# Research skills

Reusable research-writing, visualization and assessment skills maintained by Jackie Cheng.

| Skill | Purpose |
| --- | --- |
| [Personal Scientific Writing](skills/personal-scientific-writing/SKILL.md) | Evidence-supported manuscripts, verified citations, clear Methods with purposeful equations, and Results linked to finalized figures and source data. |
| [Research Visualization](skills/personal-research-visualization/SKILL.md) | Compact multipanel figures, complementary scientific encodings, semantic duplication review, redesigns with unchanged data, reproducible exports and complete panel source data. |
| [Academic Assessment](skills/personal-academic-assessment/SKILL.md) | Choosing and stress-testing a paper's research question: design limits, explicit criteria, robustness tests, wording audits, literature and priority audits that include grant reports, meeting abstracts and public deposits, optional replication in public data and an evidence-based venue verdict, kept as dated records that can be rerun before submission. |

Each folder contains `SKILL.md`, interface metadata in `agents/openai.yaml`, and supporting references where needed. Keep the complete folder together so its relative reference links remain usable.

The skills express reusable preferences rather than a fixed manuscript template or plotting style. Figure count, palette, physical dimensions, journal routing and project facts come from the current research task. Instructions distinguish computational predictions and annotations from demonstrated biological mechanisms, and preserve the scope of the work requested by the author.

The October 2026 update adds compact figure composition, palette/layout-preserving revisions, whole-set duplication review, full source-data delivery, mathematical Methods exposition and manuscript integration after data verification. The November 2026 update adds redesigns of an approved figure set with unchanged data: one shared visual language, related panels promoted from completed analyses, sensitivity runs and null ranges drawn beside the main result, build-time checks of every plotted value, and the steps for adopting approved figures into a manuscript. A second November 2026 addition, the academic assessment skill, records a general procedure for deciding which question a data set can carry and how new its answer is: candidates rated on explicit criteria, a battery of robustness tests, a wording audit, logged literature audits with searches for every asserted absence, priority checks of deposits, grant reports and meeting abstracts, pre-specified tests on public data, and a venue verdict kept apart from the robustness judgement. No research datasets, manuscript drafts or unpublished numerical results are included.
